# My first minesweeper
This is my first GitHub public repository where I attempted to recreate the popular minesweeper game. Because the JavaScript file uses import and export features, I had to set up a GitHub Pages deploytment for the easiest access possible. If you will download the project, you'll either have to set your own server or open the file through Visual Studio Code "live server" feature in order for JavaScript to work properly.

Before this repository, I have attempted to create my first minesweeper with Gemini's "Guided learning" feature, where I explicitly told to not show me the final result until I figure out how to implement it. With that I was able to write the code myself and the AI only guided me on how to approach each step. The repository work was created without the help of an AI to prove to myself that I have learned from the previous experience.
## How does the game work?
The minesweeper version works basically exactly the same as the popular minesweeper Windows edition:
- **Left click on cell** = Reveals the cell
- **Right click on cell** = Puts a flag on the cell
- **Number in the cell** = Signifies how many mines are around the specific cell
- **Size options** = Selects the size of the board
- **Difficulty options** = Selects how many mines will be deployed to the game board
- **Mine** = Game over
